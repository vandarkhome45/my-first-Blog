## 🚀 标准修改流程

```
1. 确定需求 → 2. 找到模块 → 3. 自底向上修改 → 4. 测试验证
```

### 示例：给博客添加"作者"字段

```
Step 1: BlogEntity.java
  - 添加 private String author; 字段
  - 添加 getter/setter

Step 2: BlogRepository.java
  - （可选）添加 findByAuthor 方法

Step 3: BlogService.java
  - （可选）添加按作者查询的方法

Step 4: BlogController.java
  - 修改新增/更新接口，接收 author 参数

Step 5: 测试
  - 运行 blog-api-test.http
```

## 📂 核心目录速记

```
module/          ← 业务模块都在这
├── blog/        ← 博客模块
├── comment/     ← 评论模块
└── search/      ← 搜索模块

common/          ← 公共组件（所有模块共用）
config/          ← 配置类
interceptor/     ← 拦截器
exception/       ← 异常处理
```
